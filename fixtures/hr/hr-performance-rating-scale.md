# Performance Rating Scale

The five-point year-end performance rating scale and how ratings are calibrated.

## Scale

- Ratings run from 1 (below expectations) to 5 (exceptional).

## Calibration

- Managers propose ratings, which are then calibrated in a leadership session
  before release, so ratings are consistent across teams.
