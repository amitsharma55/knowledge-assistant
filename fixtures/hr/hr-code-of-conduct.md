# Code of Conduct

The standards every employee agrees to, and how concerns are raised.

## Standards

- Conflicts of interest must be disclosed through the ethics portal.
- Gifts above a nominal value require pre-approval.

## Raising concerns

Concerns may be raised with a manager, HR, or the anonymous ethics line.
Retaliation for a good-faith report is itself a violation.
