# Security Roles

How access in Workday is granted through assignable security roles scoped to
organizations. This is the access model; the reporting org hierarchy is
described elsewhere.

## Model

- A security role grants a set of domain permissions.
- Roles are assigned on an organization, so a manager sees only their own
  team's data.

## Review

Role assignments are recertified every six months. An assignment left
uncertified past the deadline is automatically suspended.
