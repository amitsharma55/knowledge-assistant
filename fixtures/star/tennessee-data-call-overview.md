# Tennessee Data Call

The Tennessee data call is filed with the TDCI. It runs on the STAR pipeline and
uses the common data dictionary, with a Tennessee-specific scope and reporting
package.

## Submission deadline

The Tennessee filing is due April 15.

## Distinguishing elements

Tennessee requires a `seismic_zone_code` classification on each property record, reported
in a package section specific to this state.
