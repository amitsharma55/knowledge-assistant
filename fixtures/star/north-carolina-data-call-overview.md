# North Carolina Data Call

The North Carolina data call is filed with the NCDOI. It runs on the STAR pipeline and
uses the common data dictionary, with a North Carolina-specific scope and reporting
package.

## Submission deadline

The North Carolina filing is due October 31.

## Distinguishing elements

North Carolina requires a `barrier_island_zone` classification on each property record, reported
in a package section specific to this state.
