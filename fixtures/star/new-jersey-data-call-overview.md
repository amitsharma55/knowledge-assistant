# New Jersey Data Call

The New Jersey data call is filed with the NJDOBI, on the STAR pipeline and the
common data dictionary.

## Submission deadline

The New Jersey filing is due September 1.

## Distinguishing elements

New Jersey requires a `coastal_county_tier` classification on each property record.
