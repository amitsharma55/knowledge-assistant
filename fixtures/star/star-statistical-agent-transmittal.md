# Statistical Agent Transmittal

Transmits statistical-plan data to the designated statistical agent, which
aggregates industry data for regulators.

## Transmittal

- Records follow the statistical plan's fixed-width record layout.
- The agent returns an edit report; records failing edits are corrected and
  resubmitted in the next transmittal.
