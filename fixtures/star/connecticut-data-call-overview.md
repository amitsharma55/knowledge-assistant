# Connecticut Data Call

The Connecticut data call is filed with the CID. It runs on the STAR pipeline and
uses the common data dictionary, with a Connecticut-specific scope and reporting
package.

## Submission deadline

The Connecticut filing is due August 31.

## Distinguishing elements

Connecticut requires a `shoreline_zone_code` classification on each property record, reported
in a package section specific to this state.
