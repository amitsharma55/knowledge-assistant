# Kentucky Data Call

The Kentucky data call is filed with the Kentucky DOI, on the STAR pipeline and the
common data dictionary.

## Submission deadline

The Kentucky filing is due July 20.

## Distinguishing elements

Kentucky requires a `river_flood_zone` classification on each property record.
