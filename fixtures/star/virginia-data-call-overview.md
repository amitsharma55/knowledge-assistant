# Virginia Data Call

The Virginia data call is filed with the Virginia Bureau of Insurance. It runs on the STAR pipeline and
uses the common data dictionary, with a Virginia-specific scope and reporting
package.

## Submission deadline

The Virginia filing is due September 15.

## Distinguishing elements

Virginia requires a `tidewater_region` classification on each property record, reported
in a package section specific to this state.
