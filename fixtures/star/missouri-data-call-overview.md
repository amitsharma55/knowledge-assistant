# Missouri Data Call

The Missouri data call is filed with the Missouri DCI. It runs on the STAR pipeline and
uses the common data dictionary, with a Missouri-specific scope and reporting
package.

## Submission deadline

The Missouri filing is due March 31.

## Distinguishing elements

Missouri requires a `new_madrid_zone` classification on each property record, reported
in a package section specific to this state.
