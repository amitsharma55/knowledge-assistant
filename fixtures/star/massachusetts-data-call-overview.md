# Massachusetts Data Call

The Massachusetts data call is filed with the Massachusetts DOI, on the STAR pipeline and the
common data dictionary.

## Submission deadline

The Massachusetts filing is due October 15.

## Distinguishing elements

Massachusetts requires a `cape_and_islands_zone` classification on each property record.
