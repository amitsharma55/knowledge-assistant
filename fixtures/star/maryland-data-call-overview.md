# Maryland Data Call

The Maryland data call is filed with the MIA, on the STAR pipeline and the
common data dictionary.

## Submission deadline

The Maryland filing is due August 15.

## Distinguishing elements

Maryland requires a `chesapeake_zone` classification on each property record.
