# Catastrophe Model Inputs

The exposure extract STAR produces to feed the third-party catastrophe model
used for accumulation and reinsurance analysis.

## Extract

- Per-location insured values, construction, occupancy, and year built.
- The model returns an average annual loss (AAL) and an exceedance-probability
  curve per portfolio.

## Boundary

This extract feeds the model only; it is not a regulatory filing.
