# Data Call Reconciliation

How each state package is reconciled back to the financial ledger before filing,
so reported premium and exposure tie to the books.

## Steps

- Control totals are pulled from the ledger for the reporting period.
- The package aggregates are compared line by line; variances above tolerance
  open a reconciliation item.

## Sign-off

The state lead signs off the reconciliation before the package is released to
the submission portal.
