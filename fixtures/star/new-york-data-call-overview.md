# New York Data Call

The New York data call is filed with the NYDFS. It runs on the STAR pipeline and
uses the common data dictionary, with a New York-specific scope and reporting
package.

## Submission deadline

The New York filing is due November 30.

## Distinguishing elements

New York requires a `coastal_barrier_zone` classification on each property record, reported
in a package section specific to this state.
