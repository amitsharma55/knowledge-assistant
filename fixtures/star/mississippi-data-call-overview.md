# Mississippi Data Call

The Mississippi data call is filed with the Mississippi Insurance Department
(MID). It is the smallest of the coastal-state calls and reuses much of the
Florida package structure.

## Submission deadline

The MID filing is due June 15.

## Distinguishing elements

Mississippi requires a `wind_pool_flag` for policies written through the
Mississippi Windstorm Underwriting Association, reported in a separate section
from the voluntary book.
