# Data Call Scheduling Calendar

The master calendar of every state's data-call window and how the pipeline
sequences runs so overlapping deadlines do not contend for the same resources.

## Sequencing

- Runs are ordered by deadline proximity, not by state size.
- Two states due within a week are staged on consecutive nights, never the same
  night.
