# Georgia Data Call

The Georgia data call is filed with the Georgia Office of Insurance and Safety
Fire Commissioner. It uses the STAR pipeline with a Georgia-specific scope.

## Submission deadline

The Georgia filing is due July 31.

## Distinguishing elements

Georgia requires a `fall_line_region` classification separating coastal-plain
from piedmont exposure, reported on every property record.
